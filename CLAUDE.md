# CLAUDE.md

Guidance for Claude Code when working in this repository.

## What this is

JobMatch: search real jobs (via the [Tallo](https://tallo.nandan.fyi/llms.txt) API), then generate a resume and cover letter tailored to the one you pick. Built for beginners: no code, no jargon, no LaTeX.

Stack: **Astro 7** (SSR) on **Cloudflare Workers**, **D1** + Drizzle, **better-auth** (GitHub sign-in), **Vercel AI SDK** with OpenAI, Tailwind 4 with shadcn-style tokens, React islands only where interactive. Keep it minimal: prefer a library or config over hand-written code.

## Commands

```bash
pnpm dev                 # local dev (reads .dev.vars; copy .dev.vars.example)
pnpm check               # Biome + astro check (the pre-commit hook runs this)
pnpm fix                 # Biome auto-fix
pnpm test                # Vitest (pure functions only)
pnpm db:generate         # new Drizzle migration after editing src/db/schema.ts
pnpm db:migrate:local    # apply migrations to the local D1
pnpm db:migrate:remote   # apply migrations to production D1
pnpm gen:tallo           # regenerate src/lib/tallo-api.d.ts from Tallo's OpenAPI
pnpm gen:types           # regenerate worker-configuration.d.ts after wrangler.jsonc/.dev.vars changes
pnpm deploy              # build + wrangler deploy
```

## Layout

- `src/pages/` routes: `/` search, `/jobs/[id]`, `/profile`, `/resumes`, `/resumes/[id]`, `/login`, `/api/auth/[...all]`.
- `src/actions/index.ts` every server mutation (Astro Actions with Zod). Each calls `requireUser`. `saveResumeSection` merges one section into the stored profile so the per-section forms never overwrite each other.
- `src/lib/resume.ts` **single source of truth** for a resume: one Zod schema validates AI output and saved forms, and `toFormSchema` turns it into the JSON Schema that generates the editor (`@rjsf/shadcn`). `assemble` builds the tailored resume from the profile plus the model's picks (indexes and reworded bullets), so facts can never be invented or dropped. Stored JSON is always re-parsed through the schema on read, so older rows get defaults.
- `src/lib/layout.ts` page-fit model: estimates lines, `overflow`, and deterministic `trimToFit`. `src/lib/ai.ts` sends an over-long draft back to the model (up to 3 rounds, with a per-section line breakdown) and trims whatever still overflows. Recalibrate `CHARS_PER_LINE` and friends if `.resume-sheet` typography changes.
- `src/lib/prompts.ts` the writing workflow (role type, project ranking, summary variants, skill groups, page budget, cover letter). Posting text is untrusted and always wrapped in tags.
- `src/lib/ai.ts` OpenAI (`gpt-6-luna`) via `@ai-sdk/openai`. The JSON Schema is built in `output` mode so every key is required (OpenAI strict mode).
- `src/lib/tallo.ts` typed `openapi-fetch` client; results are edge-cached with `cf.cacheTtl`.
- `src/db/schema.ts` `profile` (master resume + prefs, JSON) and `application` (one tailored resume per user and posting). `auth-schema.ts` is generated by the better-auth CLI.
- `src/components/` Astro components are static; `*.tsx` are islands. `ui/` holds primitives (`variants.ts` is shared by React and Astro). `FormTemplates.tsx` gives the generated forms their grid and collapsible rows.
- `src/styles/global.css` Notion-style tokens (shadcn variable names), tag colors and the printable `.resume-sheet` (always black on white; "Download PDF" is the browser print dialog; the page scales to its column with a few lines of script).
- The sidebar is a drawer, hidden by default; the top bar always shows. On phones the nav is a tab row.

## Conventions and gotchas

- Bindings come from `import { env } from "cloudflare:workers"`. Secrets live in `.dev.vars` locally and `wrangler secret` in production.
- Biome is configured **not** to rewrite imports in `.astro` files (`useImportType` off): it cannot see template usage and would break them.
- Generated schema JSON uses `io: "input"` so every field is optional in the form; Zod fills blanks on the server.
- Email/password sign-in exists only in dev (`import.meta.env.DEV`) so the app can be tried without OAuth keys.
- Never commit `.dev.vars`. Don't hand-edit `migrations/` or `tallo-api.d.ts`.
